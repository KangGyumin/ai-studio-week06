## 2. AI 활용 기록

### [기록 1] `mock_llm.py` 불량 응답 3유형 무작위 생성
- **5요소 질문:**
  - **맥락:** Mock LLM을 활용한 파이프라인 예외 처리 테스트.
  - **목표:** 20% 확률로 3가지 불량 응답(코드펜스, 사족, 잘린 JSON)을 무작위 반환하고 발생 건수를 카운트.
  - **제약:** `random` 모듈 사용, 기존 키워드 매핑 유지, 유형별 카운팅 딕셔너리(`MALFORMED_STATS`) 포함.
  - **입력:** 기존 `mock_llm.py` 코드.
  - **출력 형식:** 완성된 파이썬 코드.
- **AI 답변 요지:** `random.random() < 0.2` 분기와 `random.choice`를 활용해 3종 불량 텍스트 반환 및 카운터 누적 로직 제안.
- **채택/기각:** **채택** (요구조건인 20% 확률 및 3종 유형 선택 완벽 부합).
- **검증 결과:** 200건 실행 시 총 36건(18%) 불량 응답이 발생했고, 3종 유형이 고르게 분포됨을 확인.

### [기록 2] `run_pipeline.py` 수정한 집계 코드 설명 요구 및 검증
- **5요소 질문:**
  - **맥락:** 200건 실행 후 실패 건수를 집계하고 코드펜스 복구 원리를 출력하는 파이프라인.
  - **목표:** 직접 작성한 집계 코드 제시 후, "실패 건수가 불량 건수보다 적은 이유"를 코드를 근거로 설명할 것 요구.
  - **제약:** 논리적 무결성 및 방어 1단계(마크다운 정규화) 동작 원리를 중심으로 설명.
  - **입력:** 본인이 직접 수정한 요약 출력 및 복구 분석 코드 블록.
  - **출력 형식:** 코드 동작 메커니즘 설명.
- **AI 답변 요지:** 코드펜스형은 방어 1단계(백틱 제거)로 정상 파싱되나, 사족형과 잘린 JSON형은 `json.loads` 에러로 제외되므로 `실패(23건) = 불량(36건) - 복구(13건)`가 성립함을 설명.
- **채택/기각:** **채택** (논리 타당성 확인).
- **본인 검증 의견:** AI의 설명대로 실제 실행 시 코드펜스 13건이 구제되어 최종 23건만 실패 처리됨을 정상 확인.
